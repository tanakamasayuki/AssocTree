## 実行ガイドと個別README

最初に[サンプル入門ガイド](../docs/GUIDE_EXAMPLES.ja.md)を読み、目的に合う例へ進んでください。

最初の候補は[Simple](Simple/README.ja.md)です。必要な機器を確認し、対象が異なる場合は下の一覧から選び直してください。

| 例 | 学ぶこと |

| [ConfigManager](ConfigManager/README.ja.md) | 設定変更・項目削除・プール領域の回収を試す |
| [ExternalBuffer](ExternalBuffer/README.ja.md) | 実行時サイズのツリーへ外部メモリを渡す |
| [IteratorDemo](IteratorDemo/README.ja.md) | ObjectのキーとArrayの添字を列挙する |
| [Simple](Simple/README.ja.md) | 小さな文書を保存・更新し、代替値付きで読み出す |
| [TypeChecks](TypeChecks/README.ja.md) | 保存した型を確認してから値を変換する |
